# Sistem Informasi Penggajian

## Deskripsi

Sistem Informasi Penggajian merupakan aplikasi berbasis web yang dirancang untuk membantu proses pengelolaan data karyawan dan penggajian secara lebih efektif dan efisien. Aplikasi ini dibangun menggunakan framework Laravel dengan Filament v4 sebagai admin panel dan MySQL sebagai sistem manajemen basis data.

---

## Tujuan

Project ini dikembangkan dengan tujuan untuk:

- Mengelola data karyawan secara terstruktur.
- Mengotomatisasi proses perhitungan gaji karyawan.
- Mengelola data tunjangan dan potongan gaji.
- Mengurangi kesalahan perhitungan gaji yang dilakukan secara manual.
- Menyediakan informasi penggajian yang akurat dan mudah diakses.
- Mempermudah proses administrasi penggajian melalui sistem berbasis web.

---
## Fitur

- Login Administrator
- Dashboard
- Manajemen Data Karyawan
- Manajemen Jabatan
- Manajemen Divisi
- Manajemen Tunjangan
- Manajemen Potongan Gaji
- Manajemen Penggajian
- Perhitungan Gaji Otomatis
- Riwayat Data Gaji

## Teknologi

- Laravel 12
- Filament v4
- PHP 8.x
- MySQL 8.0.28
