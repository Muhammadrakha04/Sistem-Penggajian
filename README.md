# Sistem Informasi Penggajian

## Deskripsi

Sistem Informasi Penggajian merupakan aplikasi berbasis web yang dirancang untuk membantu proses pengelolaan data karyawan dan penggajian secara lebih efektif dan efisien. Aplikasi ini dibangun menggunakan framework Laravel dengan Filament v4 sebagai admin panel dan MySQL sebagai sistem manajemen basis data.

## Fitur

- Login Administrator
- Dashboard
- Manajemen Data Karyawan
- Manajemen Jabatan
- Manajemen Divisi
- Manajemen Tunjangan
- Manajemen Potongan Gaji
- Manajemen Penggajian
- Perhitungan Gaji Otomatis
- Riwayat Data Gaji

## Teknologi

- Laravel 12
- Filament v4
- PHP 8.x
- MySQL 8.0.28
